# Local beta 0.3.0-beta.1 — review notes

Proposed prerelease tag: `v0.3.0-beta.1`. Publication requires the owner’s final
approval. This is a setup-required source distribution, not a standalone app.
The frozen `0.3.0-local-preview.2` artifacts are retained unchanged.

## Scope

This Track A beta retains the existing Next.js/FastAPI local research product,
manual comparisons and scoped passage/source return journey. The owner’s
original engine code and downloadable source distribution now use the standard
MIT license; dependency, article, data and model rights remain separate.
Beta status adds no license restrictions. Required attribution is retained.

All implemented Track A UI features are reachable from the extracted package.
Ordinary setup keeps the offline/manual workflow. A validated external private
settings file can explicitly opt into live PubMed, the existing pinned local
map profile, LLM query-planning proposals and AI cell proposals. Optional map
dependencies and model weights/local model serving remain separate.

The package contains no credentials, private research workspace, runtime,
compiled frontend or model weights. It includes the existing approved public
thirty-paper capture and saved map with provenance and attribution.
Track B protocol-pilot implementation and the historical separate CLI/Streamlit/
Kaggle applications are outside this beta’s packaged user-facing scope.

## Installation and limitations

Follow the archive’s `README.md`, `OPTIONAL_FEATURES.md`, `CAPABILITIES.md`,
`LICENSE`, `THIRD_PARTY_NOTICES.md` and `DISTRIBUTION_TERMS.md`. Python 3.12, Node
24 and pnpm 10.20.0 are prerequisites; setup installs locked dependencies and
builds the production frontend. Models are optional. No automatic downloads,
paid calls, remote-provider fallback or automatic human judgments are added.

Platform statement: macOS arm64 tested; Linux installation unverified; Windows
unsupported. Normal use binds loopback. Data lives outside application files.
Reopening needs the same browser profile, hostname and valid access cookie.
No account or cookie-loss access recovery is supplied. A force-killed controller
requires explicit leftover-process recovery; PID records are not authorization
to kill an unverified process. Back up only while stopped.

## Evidence and publication gate

Fresh committed-source ZIP checks, extracted setup/startup/browser round trip,
restart/drafts/exports and optional adapter checks must be recorded by source
SHA and asset checksum in the final validation report. Historical results do
not qualify this asset. Mocks, real embeddings and live calls are separate
evidence; software checks do not establish scientific quality or researcher
usefulness. Unperformed live/provider/model checks remain `NOT_RUN`.

Do not publish this note with invented source URLs or integrity values. The
local publication checklist is in `docs/releases/v0.3.0-beta.1-publication.md`.
