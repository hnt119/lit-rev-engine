# v0.3.0-local-preview.2 — release preparation

**Local preview — setup required. Unpublished pre-release candidate.**

This freezes the existing Next.js/FastAPI application, local launcher, manual
comparison/passage round trip and static portfolio review overlay. It adds no
research features, dependency upgrades, model changes, data migration or hosted
infrastructure. The portfolio and Render deployment remain separate/deferred.

## What is included

- The production frontend and thin local API, with explicit local settings,
  loopback binding, existing session/origin checks and source provenance.
- Saved public paper exploration/map, source preparation, question-linked
  manual comparison, exact passage/source inspection, drafts and exports.
- Board/cell passage-search navigation using the board's exact preparation and
  paper subset. Navigation does not execute retrieval; opening a returned
  passage does not attach evidence, assign support or submit a cell.
- A source-only ZIP with a per-file manifest, SHA256SUMS and `RELEASE.json`
  identifying the exact committed source revision. Generated assets are built
  after the source commit and are not self-referential commit inputs.
- The existing approved 30-paper public example with source-specific attribution,
  permission notices and saved map provenance. No private research data.

## Setup and support statement

**macOS 26.6.2 arm64 tested; Linux installation unverified; Windows unsupported.**
Python 3.12, Node.js 24 and pnpm 10.20.0 must be installed separately. Setup
downloads locked dependencies and builds the production frontend. This is not a
standalone installer; no runtime, prebuilt frontend, model weights or Docker
requirement is included. Models remain optional and separately configured.

Follow [the installation/launch/stop guide](../local_preview.md), also packaged
as the ZIP's README. Research data defaults to a stable private per-user
directory outside the application. Developer data paths remain unchanged;
there is no automatic import or migration.

Keep the same browser profile/hostname and protect its session cookie. Cookie
expiry/deletion or switching profiles/hostnames can lose workspace access; a
workspace ID is not a recovery key. There are no cross-device accounts or
automatic access recovery. Use controlled stop/Ctrl-C. A force-killed controller
can leave child servers holding locks and requires verified manual cleanup.
Long passages use an explicitly labelled 4,000-code-point inspector slice.

## Validation provenance

Historical working-tree results are retained separately in
[the workflow report](../comparison_passage_roundtrip.md) and
[the earlier packaging report](../local_preview_evaluation.md). They do not
validate a later source SHA or later ZIP automatically.

Fresh clean-commit setup, startup, round-trip, draft/restart/export checks,
archive hashes and skips must be recorded in `VALIDATION.md` and JSON evidence
beside the final generated assets. At source-commit time those checks have not
yet run. Their later local report, not this historical summary, establishes
the actual candidate status. Software tests do not establish researcher
usefulness, scientific support or clinical validity.
