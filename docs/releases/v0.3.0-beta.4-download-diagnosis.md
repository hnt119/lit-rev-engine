- **Download — source beta 0.3.0-beta.4** opens the readable, versioned release page.
- **Quick start** opens the [rendered beta.4 installation guide](https://github.com/hnt119/lit-rev-engine/blob/v0.3.0-beta.4/docs/local_preview.md), which explicitly identifies beta.4 and its setup requirements.
- **Direct source ZIP**, **Manifest**, **SHA-256 checksums** and **Download installation guide** remain explicit secondary downloads.
- Platform/setup links use rendered documents from the immutable beta.4 tag. No moving main guide is presented as the older download's instructions.

The release page and rendered macOS/Windows guide destinations were also checked in a fresh anonymous Chrome window at a 390-pixel viewport. All three returned HTTP 200, displayed the expected readable content and stayed within the 390-pixel page width. The initial release-page asset-link wait timed out while the Assets section was below the fold; scrolling to that lazy-loaded section exposed the ZIP link. This was corrected in the browser check, not treated as evidence of deleted assets or the cause of the user’s failure. This change does not advertise a native installer, create a mirror, move a tag, modify an asset or change its checksum.

`config/public_release.json`, `scripts/release_links.py` and their tests carry the repaired choices so regeneration cannot restore attachment-only Quick start behavior. Existing direct-download metadata remains available for offline use. The repository's existing headings/fragment anchors and PR #13's architecture documents are preserved.
