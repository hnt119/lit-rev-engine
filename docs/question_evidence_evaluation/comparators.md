# Comparator access and matched conditions

All access and execution: **NOT_RUN / NOT_CONFIGURED** for this kit. No account, subscription, feature availability, model ID or competitor capability is inferred from a public landing page. Do not purchase access or send documents without separate authorization.

| Condition ID | Intended condition | Entry gate |
| --- | --- | --- |
| usual | Participant's actual PubMed/library/PDF/spreadsheet workflow | Record tools and available source access; allow their genuine usual process. |
| llm | A capable explicitly configured LLM with the same documents and spreadsheet output | Record exact model/version/date, plan/features, context budget, tools, prompts, cost/data permission and returned usage. Unconfigured or unauthorized means NOT_RUN, not a weak substitute. |
| mature | One relevant mature product actually accessible to the participant | Record exact product/plan/features/date and task fit after access is established. No assumed paid features or screening ratings presented as passage benchmarks. |
| app | This source-bound local application | Record source SHA, profile/settings, source scope, runtime, first-run versus warm state and manual versus optional AI use. |

Use the same original document bytes/scope and five field definitions within a matched task set. Do not give the app full text while another condition receives only abstracts. If a comparator cannot accept the agreed sources, document the access limitation and separate that feasibility finding from quality/timing comparison. Preserve actual normal usage; do not intentionally cripple a comparator or silently add expert help only to the app.

Task 1 can use each tool's normal search construction, but database/date/filters and approved scientific intent must match. Actual query membership needs the same database coverage and test date. Task 2 fixes source access; app source hashes aid traceability but do not make its proposed answer correct.

For four conditions, prefer matched different document/question sets, rotated across participants. Keep per-participant exposure unique where feasible. With 3–5 people complete balance may be impossible: record actual assignments and imbalance, prior knowledge, learning and carryover. A single three-paper set repeated four times is a formative rehearsal; disclose that limitation instead of interpreting timing as causal superiority.
