# Analysis plan — blanks remain blanks

Status: proposed analysis; no results. Lock criteria in `protocol.md` before collecting data. Do not fill this document with prior automated test results or infer human usefulness from software checks.

| Measure | Definition and required disclosure |
| --- | --- |
| End-to-end time | Approved start through source-checked table/view and successful export/reopen. Include help/correction under the locked rule. Report setup, cold indexing, repeated query/provider wait and review components separately. |
| Checked-field coverage | Correct, source-supported/applicable fields divided by the predeclared assessable cells out of 15. Record honest missing/unknown outcomes and unassessable cells separately; missing information can be the correct answer. |
| Support and critical errors | Real adjudicator checks meaning/cohort/negation/numeric value/unit and cited report/version. Quote identity alone does not prove support. Define criticality before scoring and preserve disagreements/resolution. |
| Source recovery | Time and success returning from an output to the exact provided source/location; distinguish general citation from exact source support. |
| Search integrity | Exact original question/strategy/limits, translation/mapping/syntax issues, unapproved changes, unresolved concepts and expert review. |
| Known-paper recovery | Locked established held-out query membership with coverage/date/filters; capped preview recovery separately; unresolved denominators disclosed. |
| Assistance/correction | Count, category and time of actual help and edits, including source access and setup. |
| Persistence/ownership | Successful actual export/reopen and preserved view/draft; cookie loss/access failure is recorded, not normalized into success. |
| Reuse | Participant's actual voluntary response and reason, not an inferred satisfaction score. |

Report each participant and condition, completion/withdrawal, matched set and order, then descriptive medians/ranges. At this small sample size, do not assert powered noninferiority, general superiority or causal improvement from an unbalanced repeated task. Report all critical errors, failed/unsupported conditions and access restrictions. Label exploratory amendments.

Optional model ablations are separate from UX testing. Keep generator and evidence budget fixed and compare Core/BM25, Qwen and MedCPT explicitly; no silent fallback. Integration success, embeddings executing or exact quote reconstruction do not establish relevance, scientific truth or a completed systematic review.

Keep raw judgments, event logs, recordings and original exports private outside the repository. Only an explicitly approved, sanitized aggregate may later be published. A public software fixture has no participant observations or human gold unless actual adjudication is documented.
